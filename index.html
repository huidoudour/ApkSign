ApkSign

一个简洁的 Android 端 APK 签名工具，基于 Google 官方 apksig 库实现

APK 签名 密钥管理 Material You 开源

功能特性

📦 APK 签名

支持 v1 / v2 / v3 签名方案，可自由勾选组合，满足不同 Android 版本的签名需求

🔑 密钥管理

导入 JKS / BKS / PKCS12 密钥库，或在应用内直接生成新密钥，支持导出

⚡ 快速签名

从其他应用分享 APK 时，弹出简洁对话框直接完成签名，无需进入主界面

📲 签名后安装

签名完成后可选择系统中任意安装器直接安装产物，一步到位

💡 可配合 FileManager App 使用，便捷管理并选取 APK 文件进行签名

技术栈

Java + Gradle KTS AGP 9.x minSdk 29 targetSdk 36 apksig Bouncy Castle Material 3

构建

环境要求：JDK 21、Android SDK 36

./gradlew :app:assembleDebug
